プライバシーポリシー

最終更新日: 2026年11月4日

Video Grid Player（以下「本アプリ」）は、ユーザーのプライバシーを最優先に考えた設計となっています。本ポリシーでは、本アプリがどのような情報を取り扱い、どのように扱うかを説明します。

ローカル動作・通信なし

本アプリ自体はネットワーク通信を行いません。App Sandbox の設定でネットワークアクセス権限を持たず、動画データや設定情報が外部に送信されることは技術的にできません。Pro（サブスクリプション）の購入・復元・購読状態の確認は、macOS の App Store の仕組みが Apple と通信して行います。

1. 取り扱う情報

1.1 動画ファイル

  • ユーザーが Finder のドラッグ & ドロップ、またはファイル選択ダイアログから明示的に選んだ動画ファイルのみを読み込みます。
  • 動画ファイルはお使いの Mac 内で再生され、外部に送信されることはありません。
  • 動画ファイル自体を本アプリが書き換えることはありません。
  • macOS の App Sandbox による Security-Scoped Bookmark を用いて、再起動後も同じファイルへ継続アクセスできるようにしています。

1.2 スマート再生の解析（Pro）

  • スマート再生（音が鳴ったら開始・顔が映ったら開始）は、動画の音声と映像のフレームを お使いの Mac の中だけで 解析します（Apple の AVFoundation と Vision を使います）。
  • 解析の結果（再生を始める位置）は本アプリの中だけで使い、外部に送信されることはありません。顔を検出するのは顔が映っている位置を知るためだけで、誰の顔かは識別しません。
  • 解析の結果はアプリを起動している間だけメモリに保持し、ファイルには保存しません。

1.3 アプリ設定

以下の情報をお使いの Mac の中（UserDefaults と、アプリの保存領域のファイル）にローカル保存します。

  • ユーザーがカスタマイズしたキーボードショートカット
  • サイドバーで最後に選択していたタブ
  • 開いていたタブと動画、レイアウト、再生速度、スマート再生の ON/OFF
  • スマート再生の無料お試しを始めた日
  • その他のアプリ環境設定（ウィンドウ状態等）

これらはすべてお使いの Mac 内に保存され、外部に送信されることはありません。

2. 通信を行わないことの根拠

  • 本アプリは macOS の App Sandbox で配布される Mac App Store 版で、entitlements にネットワークアクセス権限（com.apple.security.network.client 等）を含みません。
  • このため、サンドボックスの仕組み上、本アプリからインターネットへの通信は技術的にブロックされます。
  • 解析サーバー、広告ネットワーク、クラッシュレポートサービスへの送信は一切ありません（Mac App Store によるアプリ受領情報を除く）。
  • Pro の購入は Apple の App Store が扱います。開発者が購入者の氏名・支払い情報などを受け取ることはありません。

3. 第三者への情報提供

本アプリはユーザーの情報を第三者に販売・貸与・共有することはありません。

本アプリは以下を行いません：

  • アクセス解析・行動トラッキング
  • 広告ネットワークとの連携
  • クラッシュレポートの自動送信
  • 使用統計の収集

4. データの削除

  • Mac App Store 版では、アプリを削除しても設定のデータ（~/Library/Containers の中）が残ることがあります。残ったデータもお使いの Mac の外には送信されません。完全に消すには、そのフォルダを削除してください。
  • 動画ファイル自体は本アプリが管理していないため、ユーザーが Finder 等で個別に削除してください。

5. ポリシーの変更

本ポリシーは法令の変更やアプリの機能追加に伴い、予告なく変更される場合があります。重要な変更がある場合はアプリのアップデート情報でお知らせします。
