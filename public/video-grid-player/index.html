Video Grid Player はローカルの動画ファイルを最大 3x3 グリッドで同時に再生できる macOS 専用アプリです。 複数の動画を同時に並べて再生・比較できます。

App Store で入手

※ macOS 14.0 (Sonoma) 以降、Apple Silicon (M1 以降) 専用。Intel Mac は非対応。

主な機能

  • 1x1 から 3x3 までのグリッドレイアウト（最大 9 本同時再生）
  • 全動画を 0 秒から同時にスタートする同期再生（Sync Start）
  • 0.5 倍〜4.0 倍の再生速度調整
  • キーボードショートカットでの効率的な操作
  • メニューバーから再生・速度・レイアウトを操作（メインウィンドウを閉じた状態でも可）
  • ドラッグ & ドロップによる簡単な動画読み込み

対応フォーマット

macOS 標準の QuickTime Player で再生できる動画なら、本アプリでも再生できます。 内部的に macOS の AVFoundation を使用しているため、追加のコーデックインストールは不要です。

確実に再生できるもの: H.264 / HEVC を含む .mp4 / .mov （iPhone やカメラ、一般的な編集ソフトの書き出し形式）。

非対応・条件付きのもの: VP9 / AV1（YouTube 等のダウンロード動画でよく使われるコーデック）は再生できません。 .mp4 拡張子のファイルでも、内部のコーデックが VP9 / AV1 の場合は再生できない点にご注意ください。 一部の .mkv / .webm はコンテナレベルで非対応となることがあります。 事前に QuickTime Player で開けるかご確認ください。
