サポート

動作環境

  • macOS 14.0 (Sonoma) 以降
  • Apple Silicon (M1 以降) 専用。Intel Mac は非対応。

対応フォーマット

macOS 標準の QuickTime Player で再生できる動画なら、本アプリでも再生できます。内部的に macOS の AVFoundation を使用しているため、追加のコーデックインストールは不要です。

確実に再生できるもの

H.264 / HEVC を含む .mp4 / .mov(iPhone やカメラ、一般的な編集ソフトの書き出し形式)。

非対応・条件付きのもの

VP9 / AV1(YouTube 等のダウンロード動画でよく使われるコーデック)は再生できません。.mp4 拡張子のファイルでも、内部のコーデックが VP9 / AV1 の場合は再生できない点にご注意ください。一部の .mkv / .webm はコンテナレベルで非対応となることがあります。事前に QuickTime Player で開けるかご確認ください。

対象拡張子

mp4, m4v, mov, mpg, mpeg, m2ts, mts, ts, 3gp, 3g2, dv
