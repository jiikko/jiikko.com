AI・開発者ツールとの連携

HTTP APIとtt-clientでサムネイル作成を自動化

1

設定でローカルAPIを有効化

アプリの設定画面から「ローカルHTTP API」をオンにします。デフォルトはオフです。有効にするとlocalhost上でHTTPサーバ（ポート18080）が起動します。

2

tt-clientをインストール

公式CLIツール tt-client を使うと、ポート番号の探索が不要になります。

3

Claude Codeなどから操作

プロジェクト・キャンバス・エレメントの作成・編集・エクスポートをAIから自動実行できます。

インストール
# Homebrewでインストール
brew install jiikko/tap/tt-client
使用例
# ステータス確認
tt-client /status

# 現在のキャンバスをプレビュー保存
tt-client --current preview -o ./thumb.png

# PNG でエクスポート
tt-client --current export -o ./output.png
ポートは自動検出されます。手動で port を調べる必要はありません。
APIの全エンドポイントは tt-client /help または tt-client '/help?topic={topic}' で確認できます。
