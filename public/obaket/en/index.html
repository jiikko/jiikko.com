Features

Browsing and uploading — the two things you do most with cloud storage — unified into a single UI across every service. No per-service client, no management console, no CLI to bounce between.

  • No separate client app per service Unlike official desktop clients, Obaket doesn't sync everything, so connecting a large bucket won't eat into your free disk space. It fetches only the files you actually open.
  • Preview on the spot, without downloading View images, videos, and text instantly, Quick Look style. Videos are fetched progressively over HTTP Range, so playback starts without waiting for a full download.
  • Upload to any cloud with the same actions Just drag & drop. Progress and failures are visualized consistently across services. Large files are split and transferred via multipart upload.
  • Download whole folders at once Supports multi-selection and recursive directory downloads. Pull files out the same way on every service.
  • Check what’s in the cloud with a single hotkey “Did I ever upload that file?” — answer it with ⌥⌘Space. Bring up the search panel from any app, type a name, and see right away whether it exists in your cloud storage. Found it? Go straight to preview or download (available for Dropbox).
  • Keep work and personal separate with profiles Connections, credentials, transfer history, and tab state are kept independent per profile. Switching profiles never mixes their data.
  • Credentials are kept safely in the Keychain Access keys and secret keys are protected by the macOS Keychain, with Touch ID support too.
  • It even cleans up after your transfers Even if a multipart upload fails partway through, Obaket automatically cleans up the leftover fragments (orphan parts) that would otherwise keep silently incurring charges.

Supported storage services

Obaket supports the storage services below (items marked "Planned" are coming soon). Supported services will keep expanding over time.

  • S3 Amazon S3 Object storage Supported
  • R2 Cloudflare R2 Zero egress fee storage Supported
  • Db Dropbox Read/write, multipart support Supported
  • PP PikPak WebDAV / browsing only Supported
  • S3+ S3-compatible Wasabi / Backblaze B2 Supported
  • SMB SMB NAS / file servers, read & write Supported
  • IA Internet Archive Public archive Supported
