プライバシーポリシー

最終更新日: 2026年11月13日

Obaket（以下「本アプリ」）は、Amazon S3・Cloudflare R2・Dropbox・Box・PikPak（WebDAV）などのクラウドストレージや、SFTP・FTP・SMB・WebDAV のサーバーを、ひとつの macOS アプリから閲覧・転送するためのクライアントです。本ポリシーは、本アプリがどのような情報を扱い、どのように保護するかを説明します。

開発者にデータは届きません

本アプリには開発者が運営するサーバーがありません。本アプリが通信するのは あなたが設定したストレージやサーバーと、その認証・配信のための宛先（2. 通信先）だけで、認証情報やファイルが開発者に送信・収集されることは一切ありません。アクセス解析・広告のためのトラッキング・使用統計の送信も行いません。

1. 取り扱う情報

1.1 認証情報（接続クレデンシャル）

  • クラウドストレージに接続するためのアクセスキー / シークレットキー、OAuth トークン、各サーバーのユーザー名・パスワードなどの認証情報は、お使いの Mac の macOS キーチェーン（Keychain）にのみ保存されます。
  • これらの認証情報が開発者やその他の第三者に送信されることはありません。各クラウドサービスへの接続にのみ使用されます。
  • 接続を書き出す機能を使うと、書き出したファイル（またはクリップボード）に認証情報が暗号化されずに含まれます。書き出したものは、あなた自身で安全に管理してください。

1.2 Mac 内に保存されるデータ

  • 接続設定: 接続名・エンドポイント・リージョン・バケット等（認証情報を除く接続のメタ情報）。Box などアカウントで接続するサービスでは、表示用のアカウント名（名前が無いときはログインのメールアドレス）も含みます。
  • キャッシュ: 表示を速くするための一覧のメタデータ（ファイル名・サイズ・更新日時など）、サムネイル、プレビューや再利用のために取得したファイル本体。
  • 転送の履歴と統計: 接続・リモートのパス・操作の種類・転送量・日時・結果やエラー。古い統計と終わった履歴は、30 日をめどに削除します。
  • 中断した操作の記録: 転送や移動を再開・後片付けするための、対象のパス・進み具合・未完了のアップロードの識別子。
  • アプリの状態: プロファイル、ウィンドウ・タブの状態、表示モード、最後に開いた場所、あなたが選んだファイルやフォルダへのアクセス許可（security-scoped bookmark）などの環境設定。
  • 診断のログ: 不具合の調査のため、操作の種類・リモートのパス・転送量・結果やエラー、一部のショートカットキーの押下、異常終了の記録を macOS のログとアプリのログ領域に残します。
  • 一時ファイル: プレビューや「他のアプリで開く」のために取得したファイルはシステムの一時領域に作成し、原則として 24 時間を過ぎたものを、起動時や次に開くときに削除します。ダウンロード中は、保存先に一時的な .part ファイルを作り、完了時に置き換えます。異常終了などで残ることがあります。

これらを開発者へ送信する機能はありません。

1.3 クラウド上のファイル

  • あなたの操作（閲覧・プレビュー・アップロード・ダウンロード・リネーム・削除など）に応じて、ファイルやそのメタデータが お使いの Mac と、あなた自身のクラウドアカウントの間で直接 やり取りされます。
  • この通信が開発者のサーバーを経由することはありません。

1.4 Box へのアクセスについて

  • あなたが Box に接続すると、本アプリは Box の OAuth 2.0 認証を通じて、あなた自身の Box アカウントの許可を得た上で Box API にアクセスします。
  • 許可を求める権限は、Box に保存されたファイルとフォルダの読み取りと書き込みです。一覧表示・プレビュー・ダウンロード・アップロード・フォルダ作成・名前の変更・移動・ファイルのコピー・削除のために使います。また、接続したアカウントの名前の表示とアップロードの上限の確認のため、Box のユーザー情報を取得します。
  • Box から受け取ったトークンは macOS キーチェーンに保存されます。接続を書き出すと、アクセストークンは書き出しに含まれますが、リフレッシュトークンは含めません（取り込んだ先では、アクセストークンの期限が切れた後に再接続が必要です）。
  • Box から取得したデータ（ファイル本体・ファイル名・フォルダ構成などのメタデータ）は、あなたが本アプリ上で行った操作を実行する目的にのみ使用されます。開発者のサーバーへの送信、広告・分析目的での利用、あなた以外の第三者への共有は一切行いません。

2. 通信先

本アプリが通信するのは、次の宛先のみです：

  • あなたが設定したクラウドストレージやサーバーの接続先（Amazon S3 / Cloudflare R2 / Dropbox / Box / PikPak の WebDAV、あなたが指定した SFTP・FTP・SMB・WebDAV のサーバーなど）。通信の暗号化は接続の種類によります。クラウドサービスと HTTPS の WebDAV は HTTPS、SFTP は SSH、FTPS は TLS で暗号化されます。暗号化しない FTP は接続の前に確認があり、HTTP の WebDAV はあなたが http:// の接続先を指定したときだけ使われます。
  • あなたが選んだサービスの API・認証・ファイル配信のホスト。Dropbox は Dropbox 社の認証サーバーと api.dropboxapi.com / content.dropboxapi.com、Box は account.box.com / api.box.com / upload.box.com と、ファイルやサムネイルの配信に使われる *.boxcloud.com / *.boxcdn.net など、Internet Archive は archive.org とそのダウンロードの配信先です。認証はいずれも、あなた自身のアカウントで行われます。
  • 同じネットワーク内の SMB サーバーの探索。SMB の接続を作る画面では、接続先の候補を出すために Bonjour（ローカルネットワーク内の探索）を使います。

上記以外への送信は行いません。

3. 第三者提供・トラッキング

本アプリは、あなたの情報を販売・貸与することはありません。あなたが転送・書き出し・「他のアプリで開く」などを行ったときは、あなたが選んだ接続先・書き出し先・アプリに、対象のデータや一時的なリンクを渡します。本アプリは以下を行いません：

  • アクセス解析ツールの使用
  • 広告や外部の分析のためのトラッキング（1.2 の診断のログは Mac 内にだけ残ります）
  • 広告ネットワークとの連携
  • クラッシュ情報・使用統計の自動送信

4. データの保存とセキュリティ

  • 認証情報と、あなたが承認した SFTP のホスト鍵・TLS 証明書の指紋は、macOS キーチェーンに保存され、OS のセキュリティ機構によって保護されます。
  • Mac App Store で配布する本アプリは、macOS の App Sandbox を有効にして動作します。
  • 通信の暗号化は、2. のとおり接続の種類によります（HTTPS・SSH・TLS）。
  • 本アプリは独自の暗号化機能を用いてユーザーデータを暗号化することはありません（通信路の暗号化は各接続の方式によります）。

5. データの削除

  • 接続の削除: アプリ内で接続を削除すると、ほかの接続が使っていない認証情報をキーチェーンから削除します。ほかの接続と共有している認証情報は残ります。
  • キャッシュのクリア: 設定の「キャッシュ」から、一覧のメタデータ・サムネイル・ファイル本体のキャッシュを消去できます。転送の履歴・統計・認証情報は対象外です。
  • プロファイルの削除: プロファイルを削除すると、そのプロファイルの接続設定・認証情報・履歴などを削除します。
  • アプリの削除: 本アプリを削除しても、Mac 内に保存した設定・キャッシュ・履歴・ログ・キーチェーンの項目がすべて自動で消えるとは限りません。必要に応じて、先にアプリ内で接続やプロファイルを削除してください。

クラウドストレージ上にあるあなたのファイルは、本アプリを削除しても削除されません。書き出した接続のファイルやダウンロードしたファイルも、あなた自身で管理してください。

6. 第三者サービスについて

本アプリは、あなた自身が契約している外部のクラウドストレージサービスに接続します。本アプリは独立したサードパーティ製クライアントであり、Amazon Web Services、Cloudflare、Dropbox、Box、PikPak とは提携・後援・推奨の関係にありません。Amazon S3、Cloudflare R2、Dropbox、Box、PikPak は各社の商標です。各サービスにおけるデータの取り扱いについては、それぞれのサービスのプライバシーポリシーをご確認ください。

7. お子様のプライバシー

本アプリは 13 歳未満のお子様を対象としたサービスではありません。本アプリは開発者に対して個人情報を収集しません。

8. ポリシーの変更

本ポリシーは、法令の変更やアプリの機能追加に伴い、予告なく変更される場合があります。重要な変更がある場合は、アプリのアップデート情報や本ページでお知らせします。
