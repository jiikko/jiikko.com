プライバシーポリシー

最終更新日: 2026年6月21日

Obaket（以下「本アプリ」）は、Amazon S3・Cloudflare R2・Dropbox・PikPak（WebDAV）などのクラウドオブジェクトストレージを、ひとつの macOS アプリから閲覧・転送するためのクライアントです。本ポリシーは、本アプリがどのような情報を扱い、どのように保護するかを説明します。

開発者にデータは届きません

本アプリには開発者が運営するサーバーがありません。本アプリは あなたが設定したクラウドストレージの接続先とのみ 通信し、認証情報やファイルが開発者に送信・収集されることは一切ありません。アクセス解析・トラッキング・広告・使用統計の送信も行いません。

1. 取り扱う情報

1.1 認証情報（接続クレデンシャル）

  • クラウドストレージに接続するためのアクセスキー / シークレットキー、OAuth トークン、WebDAV のユーザー名・パスワードなどの認証情報は、お使いの Mac の macOS キーチェーン（Keychain）にのみ保存されます。
  • これらの認証情報が開発者やその他の第三者に送信されることはありません。各クラウドサービスへの接続にのみ使用されます。

1.2 ローカルに保存される設定・キャッシュ

  • 接続設定: 接続名・エンドポイント・リージョン・バケット等（認証情報を除く接続のメタ情報）
  • 一覧メタデータのキャッシュ: 表示を高速化するためのファイル名・サイズ・更新日時などのメタデータ（ファイルの中身そのものは含みません）
  • アプリの状態: ウィンドウ・タブの状態、表示モード、最後に開いた場所、フォルダアクセス許可（security-scoped bookmark）などの環境設定
  • 一時ファイル: プレビューや「他のアプリで開く」のためにダウンロードした一時ファイル（システムの一時領域に作成され、不要になったものは自動的に削除されます）

これらはすべてお使いの Mac 内にのみ保存され、外部に送信されることはありません。

1.3 クラウド上のファイル

  • あなたの操作（閲覧・プレビュー・アップロード・ダウンロード・リネーム・削除など）に応じて、ファイルやそのメタデータが お使いの Mac と、あなた自身のクラウドアカウントの間で直接 やり取りされます。
  • この通信が開発者のサーバーを経由することはありません。

2. 通信先

本アプリが通信するのは、次の宛先のみです：

  • あなたが設定したクラウドストレージのエンドポイント（Amazon S3 / Cloudflare R2 / Dropbox / PikPak の WebDAV など）。通信はすべて HTTPS で行われます。
  • Dropbox を利用する場合、認証はあなた自身のアカウントによる OAuth を通じて Dropbox 社の認証サーバーと行われます。

上記以外への送信は行いません。

3. 第三者提供・トラッキング

本アプリは、あなたの情報を第三者に販売・貸与・共有することは一切ありません。本アプリは以下を行いません：

  • アクセス解析ツールの使用
  • ユーザー行動のトラッキング
  • 広告ネットワークとの連携
  • クラッシュ情報・使用統計の自動送信

4. データの保存とセキュリティ

  • 認証情報は macOS キーチェーンに保存され、OS のセキュリティ機構によって保護されます。
  • 本アプリは macOS の App Sandbox 環境内で動作します。
  • クラウドストレージとの通信は HTTPS（暗号化された接続）で行われます。
  • 本アプリは独自の暗号化機能を用いてユーザーデータを暗号化することはありません（通信路の暗号化は各クラウドサービスの HTTPS によります）。

5. データの削除

  • 接続の削除: アプリ内で接続を削除すると、対応する認証情報もキーチェーンから削除されます。
  • キャッシュのクリア: 設定画面からメタデータキャッシュを消去できます。
  • アプリの削除: 本アプリをアンインストールすると、本アプリがローカルに保存した設定・キャッシュは削除されます。

クラウドストレージ上にあるあなたのファイルは、本アプリをアンインストールしても削除されません。必要に応じて各クラウドサービス側で管理してください。

6. 第三者サービスについて

本アプリは、あなた自身が契約している外部のクラウドストレージサービスに接続します。本アプリは独立したサードパーティ製クライアントであり、Amazon Web Services、Cloudflare、Dropbox、PikPak とは提携・後援・推奨の関係にありません。Amazon S3、Cloudflare R2、Dropbox、PikPak は各社の商標です。各サービスにおけるデータの取り扱いについては、それぞれのサービスのプライバシーポリシーをご確認ください。

7. お子様のプライバシー

本アプリは 13 歳未満のお子様を対象としたサービスではありません。本アプリは開発者に対して個人情報を収集しません。

8. ポリシーの変更

本ポリシーは、法令の変更やアプリの機能追加に伴い、予告なく変更される場合があります。重要な変更がある場合は、アプリのアップデート情報や本ページでお知らせします。
